Live: https://loyals-ai.vercel.app
By: OCGLOBALTECH - Port Harcourt, Rivers State, NG

### What is LOYALS AI?
The first AI in Nigeria that does 3 things in 1 website:
1. **Chat AI** - Like ChatGPT - answers anything, writes business plans, school work
2. **Image AI** - Like DALL-E - creates logos, posters, product images
3. **Video AI** - Like Sora - creates short videos for TikTok, adverts

### How It Makes Money (2 Ways)
1. **Google Ads** - Free users see ads = You earn $10-$30/day (AdSense)
2. **Paid Plans - No Ads:**
   - $1 = 100 chats + 20 images (Student)
   - $3 = 500 chats + 100 images + 20 videos (Business - BESTSELLER)
   - $5 = Unlimited 30 days (Pro)

### Tech Stack
- GitHub + Vercel (Free hosting)

- Replicate API (Video)
